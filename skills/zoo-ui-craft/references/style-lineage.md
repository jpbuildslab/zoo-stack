# Style Lineage

Resolve precedence for the visual decisions in scope. Follow the user's explicit direction for the
task. For choices it leaves open, use the most recent applicable accepted example, then the
product's maintained tokens and patterns and the target's current treatment. A newer accepted change
to action placement, for example, can coexist with an older accepted decision about content width.
Check interaction, accessibility, permissions, and data against the current product contract and
implementation.

When references differ, use focused history, source, and review evidence to find the decision behind
the difference. Pin the example by path and revision or review artifact when that matters to the
comparison. Judge dimensions independently, such as hierarchy, density, typography, state treatment,
and responsive behavior.

- Preserve stable decisions the current task leaves in place.
- Carry an accepted evolution forward only in the dimensions and family it applies to.
- Preserve exceptions required by the target's task, content, accessibility, or behavior.
- Label proposed or experimental treatments as candidates and use them for exploration when
  relevant. An accepted prototype can establish presentation direction. The current product contract
  still governs live behavior and effects.

Record only the decisions that change the work. When the repository maintains pattern guidance,
record durable changes through its existing process after acceptance.
