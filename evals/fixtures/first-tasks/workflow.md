# Request desk workflow

The request desk has a native approval control for workspace coordinators. A coordinator opens a submitted request, reviews its name and time, and confirms approval. The request stays in its workspace. The approval path must remain available if a suggestion tool is unavailable.

The team may later add optional suggestions for which requests to review first. A suggestion does not carry authority to approve. The current planning grant covers local source and requirements. A hosted suggestion service and its access are undecided.
